導入：NotebookLMとは？

NotebookLMは Google の AI-powered research assistant で、インターネット全体ではなく、自分が入れたソースを根拠に答えるのが大きな特徴です。

  • 自分が渡した資料だけで考える
  • 回答に in-line citations がつく
  • 音声・図解・スライドなど別形式への変換が速い
  • ノートごとにテーマを分けて育てられる
`AIに聞く` というより、`自分の資料に聞く` 感覚に近い、という伝え方が受講者にはわかりやすいです。

第1章：なぜNotebookLMが便利なのか

NotebookLM の強さは、ソースに grounded した回答を返し、何を根拠に話しているかが見えやすいことにあります。

  1. 1 notebook = 1 project で資料を閉じ込められる
  2. チャット回答に引用がつき出典確認しやすい
  3. 資料にないことを過信しにくい
  4. 学習向けにも業務向けにも使いやすい

第2章：何を入れられるのか

NotebookLM は複数形式の資料を読み込めます。

  • PDF
  • Webサイト
  • YouTube動画
  • 音声ファイル
  • Google Docs / Slides / Sheets
  • 画像 / コピペしたテキスト

2026-08-06時点の目安

  • Standardでは 100 notebooks / user
  • 1 notebook あたり 50 sources
  • 1 source あたり 500,000 words または 200MB まで
  • Google Slides は最大100スライド
  • Google Sheets は 100k tokens 制限あり

第3章：何ができるのか

1. チャットで資料を読む

  • ノート内の資料を横断して質問できる
  • 要約、比較、論点整理、重要箇所の抽出が速い
  • 引用つきなので元資料に戻りやすい

2. Notesで知見をためる

  • チャット結果を Save to note
  • 自分で書いたメモも追加可能
  • 最大 1,000 notes / notebook

3. Mind Mapで構造をつかむ

  • 資料全体の論点を枝分かれ図で可視化
  • 初学者が全体像を掴むのに向く

4. Studioで別形式に変換

  • Audio Overview
  • Video Overview
  • Flashcards / Quizzes
  • Infographic
  • Slide Deck

第4章：Studio機能がすごい

Audio Overview

  • 2人のAIホストによる対話型音声まとめ
  • Deep Dive / Brief / Critique / Debate などの形式
  • 80+ languages 対応

Video Overview

  • 資料から動画形式の解説を生成
  • Cinematic / Explainer / Brief などの形式
  • 生成に30分以上かかることもある

Infographic / Slide Deck

  • 要点を1枚に圧縮してPNG出力
  • Detailed Deck / Presenter Slides を選べる
  • PDFに加えて PowerPoint (.pptx) でもダウンロード可能

第5章：学習機能とDeep Research

講座ではまずソース読解を本筋にしつつ、必要に応じて外部調査や復習機能へ広げると理解しやすいです。

  • Deep Research はプランごとに回数上限あり
  • Flashcards / Quizzes は復習教材にしやすい
  • Mind Map → Chat → Flashcards の流れが相性良い

第6章：サマースクール向け活用シーン

  1. 講義資料の理解: PDFやスライドを入れて難しい章だけ質問する
  2. 動画講義の時短復習: Audio Overviewで耳から復習する
  3. 発表資料の下書き: 複数資料からスライド構成を起こす
  4. 調査メモの整理: 比較観点を抽出し自分のメモまで蓄積する
  5. 学習コミュニティ運営: 講座資料やFAQを1つのノートに集約する

第7章：Claude Codeとの連携

NotebookLM を「頭脳」、Claude Code を「手足」として分けると、読む負担と作る負担を切り分けやすくなります。

  1. NotebookLMに資料を入れる
  2. 要点、論点、構成案を作る
  3. その出力を CLAUDE.md や作業メモに落とす
  4. Claude Code に実制作を渡す

第8章：注意点

  • AI生成なので事実誤認や表現ミスはあり得る
  • 引用つきでも最終確認は人が行う
  • モバイル版では一部機能制限がある
  • 共有設定や公開設定は個人アカウントとWorkspaceで差がある
`信じるために使う` のではなく、`確認しやすくするために使う`。
